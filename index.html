Firebase 設定步驟（5 分鐘）：
1. 前往 console.firebase.google.com
2. 建立新專案（任意名稱）
3. 左側「Realtime Database」→「建立資料庫」→「以測試模式開始」
4. 「專案設定」→「你的應用程式」→「Web」→ 複製 firebaseConfig
5. 貼到下方欄位（複製 { } 內的 JSON）
設定房間代碼
三位使用者需輸入相同代碼才能共享資料。請自行設定一組專屬代碼（英文+數字，至少4字）。
⚠️ 知道此代碼的人才能存取資料，請妥善保管
